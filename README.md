# Next Instagram · 수담 SUDAM

CEOS 24기 프론트엔드 5주차 과제로 만든 인스타그램 클론입니다. 홈 피드에서 사진을 넘겨보고, 작성자 이름을 눌러 프로필을 방문할 수 있습니다. 프로필에서 사진을 선택하면 보던 화면 위에 게시물 상세가 열립니다.

[배포 사이트](https://next-instagram-24th-self.vercel.app/) · [5주차 과제 안내](docs/assignment-week5.md) · [과제 제출 PR](https://github.com/CEOS-Developers/next-instagram-24th/pull/9)

## 구현 기능

### 필수 요건

- **동적 라우팅** — 사용자 이름으로 프로필(`/[username]`)을, 게시물 ID로 상세 페이지(`/p/[postId]`)를 엽니다.
- **공통 UI** — 아바타, 작성자 링크, 사진 갤러리를 컴포넌트로 분리해 홈·프로필·상세에서 재사용합니다.
- **프로필과 게시물 그리드** — 계정 정보와 작성한 게시물을 함께 보여줍니다. 넓은 화면에서는 4열, 좁은 화면에서는 3열로 표시하며 사진 위에 마우스를 올리면 좋아요와 댓글 수를 볼 수 있습니다.
- **프로필과 상세 간 이동** — 그리드에서 사진을 누르면 상세 모달이 열리고 작성자 이름을 누르면 프로필로 이동합니다. 게시물 주소로 직접 접속하거나 새로고침하면 독립된 상세 페이지가 열립니다.

### 선택 요건 및 추가 기능

| 화면 | 할 수 있는 일 |
| --- | --- |
| 홈 피드 | 최신 게시물부터 스크롤하며 보기, 여러 장의 사진을 화살표로 넘기기, 좋아요·저장 켜고 끄기 |
| 게시물 상세 | 사진 순서 확인, 좋아요 누르기, 댓글 작성 및 목록에서 확인, 닫기 버튼·Esc·배경 클릭으로 모달 닫기 |
| 내 프로필 | 이름과 소개 편집, 소개에 링크 추가, 프로필 사진 위 말풍선에 노트 작성 |
| 다른 계정 | 홈 추천 목록이나 상대 프로필에서 팔로우·언팔로우, 상대 프로필에서 변경된 팔로워 수 확인 |
| 내비게이션 | 넓은 화면에서 한글 메뉴가 있는 사이드바 사용, 모바일에서 하단 탭으로 홈·프로필 이동 |

사용자와 게시물의 기본 정보는 목데이터로 구성했습니다. 좋아요, 댓글, 저장, 팔로우와 프로필 수정 사항은 브라우저의 `localStorage`에 보관되어 같은 브라우저에서 새로고침해도 유지됩니다.

```text

│   │   ├── nav/                  # 사이드바·모바일 하단 탭
│   │   ├── post/                 # 피드 카드, 갤러리, 좋아요·댓글·저장
│   │   └── profile/              # 프로필 헤더, 편집, 노트, 게시물 그리드
│   ├── data/mock.ts              # 사용자·게시물 등 기본 데이터

```

## 실행 방법

저장소 루트에서 아래 명령을 차례로 실행합니다.

```bash
npm ci
npm run dev
```

터미널에 표시된 주소로 접속합니다. 기본 주소는 [localhost:3000](http://localhost:3000/)입니다.

| 명령 | 용도 |
| --- | --- |
| `npm run lint` | ESLint로 코드 검사 |
| `npm run build` | 타입 검사 및 프로덕션 빌드 |
| `npm run start` | 빌드한 앱 실행 |
